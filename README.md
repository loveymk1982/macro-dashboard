# 주요 경제지표 동향 대시보드 (macro-dashboard)

자동차 부품산업 관점의 환율·금리 모바일 대시보드입니다. 매주 월요일 같은 주소를 카카오톡방에 공지합니다.

- 주소: https://loveymk1982.github.io/macro-dashboard/
- 저장소: https://github.com/loveymk1982/macro-dashboard (Public)
- 화면: 휴대폰 세로 1열, 그래프는 모두 최근 1년, 환율·금리 2중축, 새로고침 버튼

## 파일 구성
| 파일 | 역할 | 수정 |
|---|---|---|
| `index.html` | 화면(그래프, 특이사항, 자동 시사점, 링크 박스). `data.json`과 `config.json`을 읽어 그립니다. | 화면 개선 때만 |
| `config.json` | 사업계획 환율(`plan`), 주간 특이사항(`notes`, 시장·일정), 자동차 부품산업 시사점(`implications`) | **매주 수정** |
| `data.json` | 자동 수집 결과(시계열). 직접 수정하지 않습니다. | 자동 |
| `scripts/collect.py` | 데이터 수집 스크립트(표준 라이브러리만 사용) | 출처 변경 때만 |
| `.github/workflows/update.yml` | 매일 한국시간 08:00(UTC 23:00) 자동 실행 설정 | 거의 없음 |

## 화면 표시 기준
- 카드의 ▲▼ 변동값: **직전 자료(전일·직전 영업일) 대비**(환율 %, 금리 %p)
- "최근 한달 최고·최저": 자료 기준일로부터 최근 30일 구간의 값(날짜 병기)
- 자동 시사점(수동 문장이 없을 때만 표시)은 한 달 전 대비 변화를 사용

## 자동으로 되는 것 (매일 오전 8시경)
GitHub Actions가 `scripts/collect.py`를 실행해 `data.json`을 갱신하고 커밋합니다. 스케줄은 수 분~수십 분 늦을 수 있습니다. 수동 실행은 Actions 탭 → update-data → Run workflow입니다.

## 매주 월요일 절차 (약 5분, 2단계 요청)
1. 월요일 08:30 이후 대시보드 맨 위 "마지막 수집" 시각이 최신인지 확인
2. **1단계 요청**: 아래 프롬프트 ①로 Claude에게 "2가지 안" 제안 요청
3. 안을 고르고(수정 요청 가능) **2단계 요청**: 프롬프트 ②로 반영 파일 요청
4. 받은 `config.json` 전체로 저장소의 `config.json` 교체 후 Commit (PC 웹, 휴대폰 브라우저, GitHub 앱 모두 가능)
5. 1~3분 뒤 대시보드 새로고침으로 확인하고 카카오톡 공지

기준일은 따로 쓰지 않아도 됩니다(Claude가 오늘 날짜를 확인). 특정 날짜 기준으로 쓰고 싶을 때만 "기준일: YYYY-MM-DD"를 적습니다.

### 프롬프트 ① 제안 요청
```
[팀장 유명곤] 이번 주 특이사항·시사점을 2가지 안(A안·B안)으로 제안해줘.

[데이터] https://loveymk1982.github.io/macro-dashboard/data.json 을 열어 환율(달러·페소·위안·루피·유로)·금리·미한 금리차의 직전 대비, 최근 한 달 최고·최저, 1년 추세를 파악해줘. (안 열리면 내가 화면 캡처를 올릴게)
[뉴스] 최근 3일 기준으로 미국(Fed·국채·달러), 한국(한국은행·물가·환율), 중국·멕시코·인도·유럽 환율, 유가·운임 뉴스를 여러 번 검색해서 신뢰도 높은 매체의 의견을 확인해줘.
[관점] 독자는 자동차 부품회사 경영진·임직원. 사업계획 환율(USD/KRW 1350, MXN/KRW 74.2, CNY/KRW 202.8, INR/KRW 14.2, EUR/KRW 1566)과 현재값의 차이를 반영해줘.
[작성 규칙] 특이사항=매크로 시장 관점 2문장, 시사점=자동차 부품산업 관점 1~2문장. 문장당 40자 안팎, 숫자·날짜 포함, 사실과 전문가 의견 구분, 투자 권유 금지, 기사 문장 인용 금지(요약), 문장 끝에 출처 링크.
[출력] A안·B안 각각 (특이사항 2문장 + 시사점 1~2문장 + 근거 링크)과 두 안의 초점 차이를 한 줄로 설명해줘. 아직 파일은 만들지 말고 내 선택을 기다려줘.
```

### 프롬프트 ② 선정 후 반영 요청
```
[팀장 유명곤] A안으로 반영해줘. (예: "A안 특이사항 + B안 시사점", 문구 수정 요청이 있으면 같이 적기)
사업계획 환율은 위 값 그대로 유지. 아래 형식으로 줘:
① config.json 전체(코드 블록 1개, 출처는 <a href='주소' target='_blank'>[매체명]</a> 형태)
② GitHub 반영 방법과 확인 방법
③ 근거 링크 목록(매체·날짜·한 줄 요약)과 주의사항
```

## 문제가 생기면
- 화면이 "데이터 준비 중": `data.json`이 없거나 첫 자동 실행 전입니다. Run workflow를 실행합니다.
- 맨 위 노란 경고: 일부 지표 수집 실패입니다. Actions → 해당 실행 → Collect data 로그의 맨 아래 `- 항목: 오류` 줄을 확인합니다.
- 특이사항이 안 바뀜: `config.json` 문법(따옴표·쉼표)과 Commit 여부를 확인합니다. 문법 오류가 있으면 화면은 이전 내용을 유지합니다.
- 공개 저장소는 60일간 활동이 없으면 스케줄이 중지될 수 있습니다(매일 데이터 커밋이 있으므로 정상 운영 중에는 문제 없음).

## 결정 사항 (변경 시 승인 필요)
- 공개 URL로 운영(사업계획 환율이 노출됨을 알고 결정)
- 유료 데이터 서비스는 사용하지 않음. 필요 시 비용 발생 전에 승인
- 특이사항은 사람이 확인하고 붙여넣는 방식(자동 게시 안 함)
